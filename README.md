# Codex로 영상 만들기

Windows에서 Codex를 이용해 영상 제작 환경을 준비하고, HyperFrames 영상의 기획과 제작을 요청하는 안내 페이지입니다. 페이지의 예시 영상과 포스터도 이 저장소에 포함되어 있습니다.

사이트: https://knowgyu.github.io/codex-video-guide/

설치 선호 선택은 브라우저에서 요청문을 바꾸는 기능입니다. 선택만으로 프로그램을 설치하거나 Codex의 권한 설정을 바꾸지 않습니다. 텔레메트리 설정이 모든 네트워크 연결이나 Codex의 모델 요청을 차단하는 것은 아닙니다.

## 파일

- `index.html`: 안내 페이지와 요청문
- `assets/video.mp4`: 안내 영상 (약 67MB)
- `assets/poster.jpg`: 영상에서 추출한 포스터
- `assets/Pretendard-Bold.otf`: Pretendard 글꼴. 사용 조건은 `assets/Pretendard-OFL.txt`를 확인하세요.

영상의 새 2D 설명과 기존 3D·음성 장면을 합친 버전입니다. 기존 장면의 내레이션을 새 말투로 전부 재합성하는 작업과 전편의 사람 청취·시청 검수는 완료되지 않았습니다.

GitHub Pages는 `main` 브랜치 루트를 사용합니다. 페이지를 수정한 뒤 같은 브랜치에 푸시하면 다시 배포됩니다.

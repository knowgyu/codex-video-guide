예시 영상 · 코드와 도구를 사용해 영상이 만들어지는 과정 파일 열기

1. 환경 준비

필요한 도구부터 확인하기

설치된 도구는 그대로 쓰고, 없는 도구는 무엇이 필요한지 먼저 확인합니다. 아래 요청을 Codex에 복사해 보내세요.

설치 선호 선택

선택한 내용은 요청문에 반영됩니다. 이 페이지에서 프로그램이 설치되거나 Codex 권한이 바뀌지는 않습니다.

환경 준비 요청
Windows에서 HyperFrames를 중심으로 영상을 만들고 싶어. 먼저 이 컴퓨터에 무엇이 설치돼 있는지 확인하고, 있는 환경은 재사용해 줘.

설치에 대한 내 선택:
- HyperFrames와 필요한 영상 제작 도구: 설치 전 물어보기
- Python과 2D 도구: 설치 거절
- Blender: 설치 거절
- VoxCPM2 로컬 음성 모델과 실행 환경: 설치 거절

winget이 있는지 확인하고, 없다면 App Installer를 설치하거나 다시 등록하는 방법을 알려 줘.
각 도구의 용도와 출처, 예상 다운로드·설치 용량, 남은 저장 공간과 관리자 권한 필요 여부를 알려 줘. 확인할 수 없는 값은 미확인이라고 적어 줘.

설치나 다운로드 전에 내 확인을 기다리고, 거절한 항목은 건너뛰어 줘. 텔레메트리는 각 도구의 공식 설정을 확인해 가능한 범위에서 끄고, 끌 수 없거나 확인하지 못한 항목은 알려 줘. HyperFrames 실행에는 HYPERFRAMES_NO_TELEMETRY=1과 DO_NOT_TRACK=1을 적용해 줘. 사용량 조회나 이벤트 전송 명령은 실행하지 말아 줘.

winget이 없다면

winget은 Windows에서 프로그램을 찾아 설치하는 도구입니다. Windows 11과 최신 Windows 10에는 보통 들어 있지만 일부 PC에는 없을 수 있습니다. Microsoft Store에서 App Installer를 설치하거나 업데이트해 보세요. 이미 설치돼 있다면 Codex에 등록 상태 확인을 부탁할 수 있습니다. Microsoft 안내

설치 전 예상 용량은 PC와 버전에 따라 달라집니다. 이 영상 제작 PC에서는 HyperFrames 패키지 폴더가 약 127MB, VoxCPM2 모델이 약 4.7GB, 별도 음성 환경이 약 1.9GB였습니다. Node.js·FFmpeg·브라우저·캐시·영상 출력물은 별도입니다.

2. 영상 제작

만들고 싶은 영상을 설명하기

대괄호 안을 원하는 내용으로 바꾸고, 참고할 영상이나 이미지를 함께 전달하세요.

영상 제작 요청
[시청자]가 [주제]를 이해할 수 있는 설명 영상을 만들어 줘.

꼭 전달하고 싶은 내용: [핵심 메시지]
참고 자료: [영상 링크나 이미지 파일, 또는 없음]
마음에 드는 점: [화면 구성, 움직임, 색감, 설명 방식 등]
형식: 한국어 내레이션과 자막이 있는 가로 영상. 길이는 내용에 맞게 정해 줘.

먼저 참고 자료에서 어떤 표현을 가져올지 살펴보고, 전체 흐름과 장면별 콘티를 짜 줘. 각 장면에서 무엇을 보여주고 어떻게 움직일지, 앞 장면과 어떻게 이어질지, 내레이션은 무엇인지 적어 줘. 참고 자료가 없으면 방향을 제안해 줘.

대표 장면을 먼저 만들어 화면을 확인하고, 그 결과를 바탕으로 나머지 장면을 이어서 만들어 줘. 같은 화면이나 설명이 반복되는지도 살펴봐 줘. 실제 자료와 예시를 구분하고, 완성 후 영상·자막·음성을 확인해 결과 파일과 확인하지 못한 부분을 알려 줘.

기획할 때 함께 전하면 좋은 것

  • 레퍼런스: 링크와 함께 어느 장면의 무엇이 좋은지 적어 주세요. 예를 들어 “색감”보다 “화면이 확대되며 다음 장면으로 이어지는 방식”처럼 구체적이면 좋습니다.
  • 장면별 역할: 시청자가 각 장면에서 무엇을 이해해야 하는지 정하면 비슷한 설명을 줄이기 쉽습니다.
  • 검토할 장면: 대표 장면을 먼저 보고 구도와 움직임을 고친 뒤 나머지를 만들면 방향을 맞추기 쉽습니다.
